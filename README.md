# Cortex open-redirect canary

This repository hosts a passive security-research canary for the authorized
`cortex.atmeta.com` open-redirect proof of concept.

The page contains no JavaScript, forms, analytics, cookies, or credential
collection.

Expected public URL:

```text
https://cortex.atmeta.co/codex-cortex-redirect/
```

Canary:

```text
META-CORTEX-OPEN-REDIRECT-2026-10-09
```
